# Discord Badge Utility

Приложение для Windows, которое помогает получить значки профиля Discord
**«Универсал»** и **«Время в играх»**.

Программа запускает на компьютере собственные фоновые процессы с именами игр из
официального списка Discord. Клиент Discord видит их так же, как обычные запущенные
игры, и засчитывает игровую активность.

> ⚠️ **Приложение не связано с Discord Inc.** и не одобрено Discord.
> Эмуляция игровой активности нарушает Terms of Service Discord.
> Используйте на свой риск.

---

## Что нужно

- Windows 10 или 11, 64-битная.
- Установленный клиент Discord для Windows.
- Интернет — только чтобы один раз скачать список игр. Дальше можно работать офлайн.

Права администратора не нужны.

---

## Установка

### Portable-версия (проще всего)

1. Скачайте файл `discord-badge-utility_0.1.0_x64_portable.exe` со страницы
   [Releases](https://github.com/nellzdsg/discord-badge-utility/releases).
   Номер версии в имени файла может быть новее.
2. Положите его в любую папку — например, на рабочий стол.
3. Запустите двойным кликом.

Установка не требуется: удалить программу — значит просто удалить этот файл.

### Установщик

1. Скачайте `discord-badge-utility_0.1.0_x64_setup.exe`.
2. Запустите и следуйте подсказкам.
3. После установки ярлык появится в меню «Пуск».

Установка выполняется для текущего пользователя, без прав администратора.

### Если Windows предупреждает

Файлы не подписаны платным сертификатом, поэтому SmartScreen может показать окно
«Windows защитила ваш компьютер». Нажмите **«Подробнее» → «Выполнить в любом случае»**.

Это обычное поведение для небольших открытых проектов без платной подписи.

## Первый запуск

1. Прочитайте дисклеймер и поставьте галочку, что понимаете риски.
2. Откройте вкладку **«База игр»** и нажмите **«Обновить базу»**.
   Скачается публичный список игр Discord (около 4 МБ) и сохранится на 12 часов.
3. Убедитесь, что Discord запущен. Индикатор в правом верхнем углу должен показывать
   «Discord запущен».

После этого можно пользоваться любой из двух вкладок.

## Как пользоваться

### «Универсал» — для значка за разные игры

Вкладка перебирает игры из базы небольшими группами (батчами) и запускает их по очереди.

1. Откройте **«Универсал»**.
2. При необходимости измените настройки. Значения по умолчанию подходят большинству.
3. Нажмите **«Запустить»**.
4. Дождитесь окончания или нажмите **«Остановить»** в любой момент.

Что означают настройки:

| Настройка | Что делает |
| --- | --- |
| **Игр в батче** | Сколько игр запускается одновременно. 6–8 — безопасный вариант. |
| **Удержание** | Сколько секунд каждая группа остаётся запущенной. 10–20 секунд достаточно. |
| **Лимит игр** | Сколько игр обработать за запуск. Пустое поле — обработать все. |
| **Пропускать уже обработанные** | Не тратить время на игры, которые уже есть в истории. |
| **Исключить 18+** | Пропускать игры для взрослых. |
| **Кулдаун каждые / длительность** | Короткий перерыв после каждых N групп, чтобы нагрузка не была постоянной. |
| **Разброс времени** | Слегка случайная длительность удержания. Полезно, если не хотите идеально ровного ритма. |

Во время работы видно прогресс, число успешных и неуспешных запусков, прошедшее и
оставшееся время, а также список активных игр.

**Совет:** не ставьте слишком большой батч и не запускайте программу одновременно с
играми, где работает античит.

### «Фарм часов» — для значка за время в играх

Здесь выбранные игры остаются запущенными, пока вы не остановите фарм.

1. Откройте **«Фарм часов»**.
2. Найдите игры через поиск и отметьте до 20 штук. Выбор запоминается.
3. Нажмите **«Запустить фарм»**.
4. Оставьте приложение и Discord открытыми.
5. Когда хватит — нажмите **«Остановить»**.

20 игр одновременно дают до 20 часов игрового времени за один реальный час.
Если какой-то процесс завершится сам, приложение попробует запустить его снова.

### «База игр» — список игр Discord

- **Обновить базу** — скачать свежий список.
- **Поиск** — по названию или ID игры.
- **Все / Процессы / RPC** — фильтр по способу запуска.
- **Только новые** — показать игры, которых ещё нет в истории.
- Метка **«было»** — игра уже обрабатывалась.
- Метка **18+** — игра для взрослых.

Для работы приложения важны только игры с меткой `exe` — они запускаются как процессы.

### «Настройки» — офлайн-режим и история

- **Офлайн-режим** — приложение не делает сетевых запросов и берёт базу только из
  сохранённого кэша. Если кэша нет, сначала загрузите базу при выключенном офлайн-режиме.
- **История игр** — список уже обработанных игр. Его можно выгрузить в JSON, скопировать,
  импортировать на другом компьютере или очистить.
- **Папка данных** — открывает папку, где хранятся настройки, история и кэш.
- **О программе** — версия, ссылка на исходный код и лицензия.

### «Консоль» — журнал событий

Показывает, что происходит в реальном времени: запуск групп, ошибки, перезапуски,
завершение работы. Если что-то пошло не так, начните с этой вкладки.

---

## Где хранятся данные

В папке `%APPDATA%\DiscordBadgeUtility`:

- `history.json` — обработанные игры;
- `settings.json` — настройки;
- `games_cache.json` — сохранённая база игр.

Папка Discord и его файлы не затрагиваются.

---

## Безопасность и приватность

Приложение:

- не просит токен, пароль или QR-код;
- не читает папку Discord, `Local Storage`, cookies и кэш клиента;
- не внедряется в процессы, не патчит память, не устанавливает DLL и хуки;
- не изменяет файлы клиента Discord;
- не отправляет телеметрию и аналитику;
- не содержит фонового автообновления.

**Единственный сетевой запрос** — публичный список распознаваемых игр Discord
(`discord.com/api/v9/applications/detectable`). Ответ кэшируется на 12 часов.
Офлайн-режим отключает и этот запрос.

Все запускаемые процессы — собственные процессы-пустышки приложения. Они автоматически
завершаются вместе с программой, а временные файлы удаляются.

---

## Почему значок не появился сразу

- Discord обновляет значки с задержкой до 24 часов, иногда дольше.
- Discord должен быть запущен всё время, пока работает программа.
- Точные требования Discord к количеству игр и часов не публикует, поэтому результат
  не гарантирован.
- Попробуйте перезапустить Discord и проверить профиль на следующий день.

## Частые вопросы

**Приложение не видит Discord.**
Запустите клиент Discord для Windows и подождите несколько секунд — индикатор
обновится сам.

**База игр не загружается.**
Проверьте интернет. Если включён офлайн-режим, выключите его в настройках и повторите.
Если сервер Discord временно недоступен, приложение использует сохранённый кэш.

**Антивирус или SmartScreen блокирует файл.**
Файлы не подписаны сертификатом. Если вы скачали их со страницы Releases этого
репозитория и контрольная сумма совпадает, добавьте файл в исключения или используйте
portable-версию.

**Процессы остались в диспетчере задач.**
Обычно они закрываются вместе с приложением. Если программа завершилась аварийно,
завершите процессы вручную или перезагрузите компьютер.

**Вкладка Discord «Зарегистрированные игры» стала тормозить.**
После большого числа игр клиент Discord может замедлиться — это его локальный кэш.
Помогает очистка `%APPDATA%\discord\Local Storage` (Discord при этом нужно закрыть).
Учтите, что вместе с кэшем сбросятся некоторые локальные настройки клиента.

**Можно ли получить ограничение аккаунта?**
Эмуляция активности нарушает Terms of Service Discord, поэтому такой риск существует.
Решение принимает только Discord.

**Можно ли запускать вместе с играми?**
С играми без античита — можно. С античит-играми (Valorant, CS2, Rust, Fortnite, Apex
и подобными) — нельзя.

## Проверка скачанного файла

Рядом с exe лежит `SHA256SUMS.txt` с контрольными суммами. Проверить файл можно в
PowerShell:

```powershell
Get-FileHash .\discord-badge-utility_0.1.0_x64_portable.exe -Algorithm SHA256
```

Полученный хеш должен совпасть со строкой в `SHA256SUMS.txt`.

## Удаление

- **Portable:** удалите exe-файл.
- **Установленная версия:** «Параметры → Приложения → Discord Badge Utility → Удалить».
- **Данные:** при желании удалите папку `%APPDATA%\DiscordBadgeUtility`. Это сбросит
  историю и настройки.

## Ограничения и риски

- Результат не гарантирован: решение о значках принимает Discord.
- Эмуляция игровой активности нарушает ToS Discord. Аккаунт теоретически может получить
  ограничение.
- Не запускайте программу одновременно с играми, где работает античит.
- Приложение не подписано сертификатом, поэтому Windows может показывать предупреждения.
